# Crave House email OTP setup

Crave House uses a six-digit email OTP. Do not use the Supabase Magic Link button for this flow.

## Magic Link / OTP template

Subject:

`Your Crave House verification code`

HTML body:

```html
<h2>Verify your Crave House account</h2>
<p>Use the 6-digit verification code below to continue:</p>
<p style="font-size:32px;font-weight:700;letter-spacing:8px;">{{ .Token }}</p>
<p>This code expires shortly and can only be used once.</p>
<p>If you did not request this code, you can safely ignore this email.</p>
<p>Crave House<br>Whatever You’re Craving.</p>
```

The application verifies the value with Supabase Auth using the email address and the six-digit token. The user should copy the six-digit number from the email and paste it into the Crave House verification screen.

## Important

The code is generated by Supabase for each request. It cannot be hard-coded into the application or generated manually by the frontend.

For production, configure the Supabase Site URL and redirect allow-list to the live Crave House URL. The OTP flow itself does not require the user to click the email link.
